# VideoOps

**VideoOps** is a cloud-based video processing and automation platform designed to help businesses, content creators, and digital agencies efficiently manage, convert, and optimize video content.

The platform aims to simplify video workflows through automated video transcoding, format conversion, resizing, and bulk processing for different platforms and devices.

Powered by **FFmpeg**, VideoOps is being designed for scalable cloud infrastructure, asynchronous processing, and reliable background job execution.

### Key Features

- Automated video conversion and transcoding
- Multiple output presets (Vertical, Square, Landscape)
- Asynchronous video processing and job tracking
- Video metadata extraction and validation
- Bulk video processing (planned)
- AWS S3 cloud storage integration (in progress)
- Distributed processing using AWS SQS and Docker workers (planned)

### Technology Stack

**Frontend:** Angular (Planned)

**Backend:** Java, Spring Boot, FFmpeg, PostgreSQL, Flyway, Maven

**Cloud & Infrastructure:** AWS S3, AWS SQS, Docker
